# Third-party asset policy — private all-in-one delivery

This private user-specific package includes the exact `minecraft.zip` supplied by the user at
`app/bundled_assets/minecraft.zip`. It is integrated for local CPU-textured rendering and is
automatically selected by the CLI, Python API, AI tool bridge, snapshot workflow, patch previews,
and autonomous construction loop.

The source archive is intended for the requesting user’s private Snowflake/CoCo environment. Do
not publish or redistribute the bundled proprietary game assets without authorization. Explicit
user resource packs and legally obtained client JARs may override the bundle.
