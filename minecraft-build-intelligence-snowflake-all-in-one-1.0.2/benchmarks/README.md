# Benchmarks

The benchmark matrix covers 16³, 64³, 100³, 128³, sparse 256×128×256, high-palette, many-region, transparency, non-cube, and block-entity stress fixtures. Record parse voxels/s, chunk ratio, first preview, frame time, snapshot time, analysis time, patch/export time, RSS, browser heap, draw calls, triangles, textures, and GPU estimates.
